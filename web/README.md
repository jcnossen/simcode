# SIMCODE bead calibration

Use TorchPSF commit `9d058ff` or a compatible later version. Install the TorchPSF web dependencies with `npm ci` in its web directory. From this directory run `node serve.mjs` and open http://127.0.0.1:5177 in a WebGPU browser. Use `node serve.mjs --build` for a self-contained static site. A sibling torch-psf checkout is discovered automatically, or set TORCH_PSF_WEB to its web directory.

Open **Example: randomly generated bead movie** below the file inputs to watch a 100-frame, 400 × 400 movie render from 12,000 randomly placed beads. Each frame uses the current optical and camera settings, two 200 nm illumination patterns, and XYZ drift with a ±0.5 µm axial excursion (1 µm peak to peak). The right-hand preview shows the true point-emitter PSF at the current focus and XYZ displacement relative to frame one. Use the frame slider or scroll over the movie to browse exposures. Hover over a location to see an enlarged ROI with the phase-matched illumination blended in. The generated movie uses random Noll 5-11 aberrations and shows its simulated pattern. During estimation, the overlay becomes available from preliminary fitted bead intensities and is replaced with the final fitted pattern. Axial drift is evaluated with a moving vectorial PSF lookup table. Beyond the measured stack range, the fitted pupil is extrapolated. Choose **Estimate generated movie** to fit the completed TIFF. The estimator replaces the input form and plays the current camera frame as it is read and fitted. Back to inputs restores the file selection. The estimator displays the current point PSF, optical search score, focus, Z6 astigmatism and per-frame drift. With a calibration stack it also displays the stack fit likelihood during pupil estimation. Closing the view during generation cancels it.

Choose **View pupil and aberrations** during or after fitting for the normalized amplitude, phase in waves and signed coefficients by Noll index. Movie-only fits profile signed Noll modes 5 through 11. A calibration stack fits the same modes with through-focus data. The PDF report also includes through-focus PSF sections and is available separately and inside the archive.

Valid acquisition settings are remembered in a first-party browser cookie for one year. The optional stack step can be cleared to restore automatic TIFF spacing.

Supply one grayscale multipage TIFF movie (TYX). Use the raw six-exposure sequence A 0/120/240°, then B 0/120/240°, repeated, with the first exposure at A0. The optional single-channel calibration TIFF (ZYX) may cover a different field from the same microscope. For a reverse sweep enter a negative step. The step override takes priority over the OME/ImageJ metadata. Confirm the example optical and camera settings for your acquisition.

TorchPSF renders a finite-bead vectorial focus table on WebGPU, seeds positions from the mean and its residual, and jointly apportions shared pixel counts to overlapping beads. Per-frame photometry and XYZ drift alternate with a common pupil fixed across the movie. XY drift is limited to ±4 pixels around the mean coordinates. Movie-only optics use a signed coordinate search over Noll modes 5 through 11 and can have a defocus sign ambiguity. A stack uses the TorchPSF bead calibration on selected reference ROIs and fixes the multi-mode pupil before movie fitting. Localizations below optical resolution can remain merged.

SIMCODE fits the first temporal harmonic to each bead for each illumination direction, estimates the spatial carrier, corrects the phase for XY motion, and fits quadratic field surfaces. Depth is corrected for uniform fluorescent sphere diameter. Angles refer to the wavevector measured from +x toward +y in image coordinates. Maps extrapolate in regions with few beads. Downloads include the reusable point-emitter PSF archive, frame-aligned bead fit, modulation coefficients and sampled fields, and the field overview PNG.
