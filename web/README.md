# SIMCODE bead calibration

The local gel preview requires a sibling TorchPSF checkout containing `web/src/dense/gel.ts`. Install the TorchPSF web dependencies with `npm ci` in its web directory. From this directory run `node serve.mjs` and open http://127.0.0.1:5177 in a WebGPU browser. Use `node serve.mjs --build` for a self-contained static site. A sibling torch-psf checkout is discovered automatically, or set TORCH_PSF_WEB to its web directory.

### 3D bead gel

Slide and gel use the same movie input, optional calibration stack, optical and camera settings, illumination sequence and Estimate button. Gel movies contain one complete illumination cycle at each focus stop. The fitter estimates relative focus directly from the TIFF. It compares the contrast of cycle-averaged bead images against the axial autocorrelation of the finite-bead vectorial PSF, then refines each focus stop against the shared bead volume. The axial origin and direction are conventions. Axial sample drift and scan motion appear together in the inferred focus trajectory. The 64 by 64 pixel gel example scans 10 micrometres and follows the same TIFF fitting path as an upload.

The [same-movie reconstruction comparison](gel-reconstruction.md) measures the effect of the PSF sampling grid, optical seed offsets, focus initialization and extra joint refinement rounds. New example TIFFs carry their numerical sampling grid in ImageJ metadata and can be reopened as ordinary uploads.

The compute worker estimates the shared pupil from registered patches and refines it with the overlapping bead positions, brightness, background and XYZ drift. WebGPU evaluates the vectorial PSF, the combined camera image and the position and brightness derivatives for every bead. For per-exposure photometry, WebGPU builds a shared Poisson-weighted intensity matrix. A double-precision Cholesky solve fits the exposures in each illumination cycle, with a brightness prior for poorly observed beads. The fitter seeds XYZ from local maxima of a 3D difference-of-Gaussians volume, using the same smoothing scales, threshold and neighbourhood as Python. In crowded volumes these candidates initialize the shared pupil and drift. For two sequential three-phase axes, SIMCODE then measures the two illumination carriers and combines their phase-resolved scan volumes with the mean volume to propose additional beads. TorchPSF refines these against the original counts, searches the background-subtracted 3D residual, and removes very faint components relative to nearby beads. A broad bead-brightness distribution can reduce sensitivity to dim beads near bright ones. For untagged movies the browser uses the Python gel table support: 256 by 256 half-camera-pixel lateral samples and 256 axial samples at 0.1 micrometre spacing, from -12.8 to +12.7 micrometres. Interpolation at the edges uses zero padding. All beads participate in each intensity solve. Only measurements within 0.55 micrometre of fitted focus enter the per-bead modulation estimator. Geometry uses a damped block update. SIMCODE fits signed 3D illumination wavevectors from near-focus bead intensities. Results include XY/XZ PSF slices, Noll coefficients, modulation depths and intensity ratio. Downloads include the point-emitter PSF archive, per-exposure bead photometry, drift and modulation. For uniformly random gels where most fitted beads overlap a neighbour, the default depth estimate uses the shot-noise-corrected spatial power of the first illumination harmonic relative to the mean. The result table and JSON also retain the depth from individual bead intensities. Clear the uniformly random bead positions checkbox for clustered or structured samples. Generated ground truth is used for display.

Open **Example: randomly generated bead movie** below the file inputs to watch a 400 × 400 movie (40 frames by default, adjustable under **Example frames**) render from 12,000 randomly placed beads. Each frame uses the current optical and camera settings, one 200 nm illumination pattern per selected axis, and independent Gaussian random walks in X, Y and Z. Each trajectory is rescaled once per movie to span 0.56 and 0.42 camera pixels laterally and −200 to +200 nm axially around the 80 nm focus offset. The drift trace is relative to the first frame. The top row shows the frame, pattern zoom and true point-emitter PSF at the current focus. The centered drift trace below shows XYZ displacement relative to frame one. Use the frame slider or scroll over the movie to browse exposures. Hover over a location to see an enlarged ROI with the phase-matched illumination blended in. The generated movie uses random Noll 5-11 aberrations and shows its simulated pattern. During estimation, the overlay becomes available from preliminary fitted bead intensities and is replaced with the final fitted pattern. Axial drift is evaluated with a moving vectorial PSF lookup table. Beyond the measured stack range, the fitted pupil is extrapolated. Choose **Estimate** beside the movie input to fit the completed TIFF. The estimator replaces the input form and plays the current camera frame as it is read and fitted. Back to inputs restores the file selection. The estimator displays the current point PSF, optical search score, focus, Z6 astigmatism and per-frame drift. With a calibration stack it also displays the stack fit likelihood during pupil estimation. Closing the view during generation cancels it.

Choose **View pupil and aberrations** during or after fitting for the normalized amplitude, phase in waves and signed coefficients by Noll index. Movie-only fits profile Noll modes 5 through 11 against registered bead shapes, spatial power and the asymmetric third-order correlation of individual exposures. The live TorchPSF column chart shows the current estimate and, for generated examples, the simulated truth. Focus and even-mode signs can remain ambiguous. A calibration stack fits the same modes with through-focus data. The PDF report also includes through-focus PSF sections and is available separately and inside the archive.

Valid acquisition settings are remembered in a first-party browser cookie for one year. The optional stack step can be cleared to restore automatic TIFF spacing.

Supply one grayscale multipage TIFF movie (TYX). Set the bead diameter beside the movie input. Choose the number of axes, phases per axis (1–10), and whether the acquisition interleaves them. The angle-index preview shows one repeating cycle starting at axis 0 and phase 0°. Nominal steps are equally spaced over 360°. With at least three steps, select **Estimate phases individually** to fit each repeating exposure slot independently for each axis. The first slot is the 0° reference. Phase estimates appear in the result table and in each pattern's `phase_steps_rad` in modulation.json. One- and two-phase acquisitions support PSF, drift, and bead photometry. The optional single-channel calibration TIFF (ZYX) may cover a different field from the same microscope. For a reverse sweep enter a negative step. The step override takes priority over the OME/ImageJ metadata. Confirm the example optical and camera settings for your acquisition.

TorchPSF renders a finite-bead vectorial focus table on WebGPU, seeds positions from the mean and its residual, and jointly apportions shared pixel counts to overlapping beads. Per-frame photometry and XYZ drift alternate with a common pupil fixed across the movie. XY drift is limited to ±4 pixels around the mean coordinates. Movie-only optics start with a signed coordinate search over Noll modes 5 through 11. With at least five complete illumination cycles and a field at least 96 pixels across, TorchPSF refines the shared pupil using through-focus diversity. Averaging a complete cycle reveals the same stationary bead field at different focuses. The optimizer fits relative complex optical transfer across cycles, eliminating the unknown bead texture and allowing lateral drift. It tries both focus signs. The fitter tracks individual exposures by comparing their spatial power spectra with repeats of the same illumination phase. It accounts for focus variation within each averaged cycle when refining the pupil. A weak fit or insufficient focus diversity leaves the coarser estimate in place. Review the fit summary to see which method was used. A stack uses the TorchPSF bead calibration on selected reference ROIs and fixes the multi-mode pupil before movie fitting. Localizations below optical resolution can remain merged.

SIMCODE fits the first temporal harmonic to each bead for each illumination direction, estimates the spatial carrier, corrects the phase for XY motion, and fits quadratic field surfaces. For dense random, stationary bead fields, field depth uses the ratio of first-harmonic image power to DC image power over complete cycles. A difference-of-Gaussians filter isolates spatial bead texture, and the diagonal phase covariances are corrected for photon shot noise. This assumes the optical blur varies slowly within a phase cycle and the local bead positions are spatially uncorrelated. The bead-trace estimate is retained as `bead_depth` in modulation.json. Sparse fields, small images and carriers too close to the texture band use bead photometry. Both depth estimates include the uniform fluorescent sphere correction. Angles refer to the wavevector measured from +x toward +y in image coordinates. Maps extrapolate in regions with few beads. Downloads include the reusable point-emitter PSF archive, frame-aligned bead fit, modulation coefficients and sampled fields, and the field overview PNG.

For generated movies, the preview renders the aberrated point PSF used for the simulation. The estimator displays the simulated and fitted PSFs together, with true and estimated Noll coefficients, focus, XYZ drift, pattern pitch, orientation, phase steps, wavevector components, modulation depth, phase and intensity ratio across the field. Drag across a depth or intensity-ratio map to inspect fitted values and available simulation truth at a camera location. Expand the field coefficients to inspect all terms of the quadratic surfaces. True and estimated depth and ratio maps share a scale in the overview PNG. The complete simulated pattern is available in true-modulation.json. Truth is retained in the browser for the selected generated movie and is used only for display. The Reconstruction panel overlays fixed bead positions on the selected frame after XY drift correction. For generated movies, blue crosses mark first-frame ground truth registered to the same static coordinate system. Zoom or pan to move the dotted ROI in the input movie. Zernike chart and table values are in milliwaves RMS (1000 mλ per wave). Uploading a TIFF runs the ordinary fit.

See [the matched depth benchmark](depth-benchmark.md) for true-pupil and true-drift controls on identical pixels.

On three sinusoidal-drift benchmark movies of 100 frames each of 12,000 planar 40 nm beads (two independent seeds, axial excursions of ±200 or ±500 nm), signed coefficient RMS error across Noll 5–11 was 0.0205, 0.0781 and 0.0086 waves for the coarse fit. The Python reference obtained 0.00029, 0.00058 and 0.00076 waves. WebGPU obtained 0.00025, 0.00079 and 0.00075 waves on the same pixels. The generator and fitter share a vectorial optics model. Experimental accuracy has not been measured in this comparison.

See the [seven-movie random-walk benchmark](https://github.com/jcnossen/torch-psf/tree/a820ba9/study/simcode_random_walk) for the Python simulator, focus refinement, and per-seed comparisons at 12,000 and 1,200 beads.
