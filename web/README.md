# SIMCODE bead calibration

Use TorchPSF commit `de05b60` or a compatible later version. Install the TorchPSF web dependencies with `npm ci` in its web directory. From this directory run `node serve.mjs` and open http://127.0.0.1:5177 in a WebGPU browser. Use `node serve.mjs --build` for a self-contained static site. A sibling torch-psf checkout is discovered automatically, or set TORCH_PSF_WEB to its web directory.

Open **Example: randomly generated bead movie** below the file inputs to watch a 400 × 400 movie (100 frames by default, adjustable under **Example frames**) render from 12,000 randomly placed beads. Each frame uses the current optical and camera settings, one 200 nm illumination pattern per selected axis, and XYZ drift with a −200 to +200 nm axial excursion. The top row shows the frame, pattern zoom and true point-emitter PSF at the current focus. The centered drift trace below shows XYZ displacement relative to frame one. Use the frame slider or scroll over the movie to browse exposures. Hover over a location to see an enlarged ROI with the phase-matched illumination blended in. The generated movie uses random Noll 5-11 aberrations and shows its simulated pattern. During estimation, the overlay becomes available from preliminary fitted bead intensities and is replaced with the final fitted pattern. Axial drift is evaluated with a moving vectorial PSF lookup table. Beyond the measured stack range, the fitted pupil is extrapolated. Choose **Estimate generated movie** to fit the completed TIFF. The estimator replaces the input form and plays the current camera frame as it is read and fitted. Back to inputs restores the file selection. The estimator displays the current point PSF, optical search score, focus, Z6 astigmatism and per-frame drift. With a calibration stack it also displays the stack fit likelihood during pupil estimation. Closing the view during generation cancels it.

Choose **View pupil and aberrations** during or after fitting for the normalized amplitude, phase in waves and signed coefficients by Noll index. Movie-only fits profile Noll modes 5 through 11 against registered bead shapes, spatial power and the asymmetric third-order correlation of individual exposures. The live TorchPSF column chart shows the current estimate and, for generated examples, the simulated truth. Focus and even-mode signs can remain ambiguous. A calibration stack fits the same modes with through-focus data. The PDF report also includes through-focus PSF sections and is available separately and inside the archive.

Valid acquisition settings are remembered in a first-party browser cookie for one year. The optional stack step can be cleared to restore automatic TIFF spacing.

Supply one grayscale multipage TIFF movie (TYX). Set the bead diameter beside the movie input. Choose the number of axes, phases per axis (1–10), and whether the acquisition interleaves them. The angle-index preview shows one repeating cycle starting at axis 0 and phase 0°. Nominal steps are equally spaced over 360°. With at least three steps, select **Estimate phases individually** to fit each repeating exposure slot independently for each axis. The first slot is the 0° reference. Phase estimates appear in the result table and in each pattern's `phase_steps_rad` in modulation.json. One- and two-phase acquisitions support PSF, drift, and bead photometry. The optional single-channel calibration TIFF (ZYX) may cover a different field from the same microscope. For a reverse sweep enter a negative step. The step override takes priority over the OME/ImageJ metadata. Confirm the example optical and camera settings for your acquisition.

TorchPSF renders a finite-bead vectorial focus table on WebGPU, seeds positions from the mean and its residual, and jointly apportions shared pixel counts to overlapping beads. Per-frame photometry and XYZ drift alternate with a common pupil fixed across the movie. XY drift is limited to ±4 pixels around the mean coordinates. Movie-only optics use a signed coordinate search over Noll modes 5 through 11 and can have a defocus sign ambiguity. A stack uses the TorchPSF bead calibration on selected reference ROIs and fixes the multi-mode pupil before movie fitting. Localizations below optical resolution can remain merged.

SIMCODE fits the first temporal harmonic to each bead for each illumination direction, estimates the spatial carrier, corrects the phase for XY motion, and fits quadratic field surfaces. For dense random, stationary bead fields, field depth uses the ratio of first-harmonic image power to DC image power over complete cycles. A difference-of-Gaussians filter isolates spatial bead texture, and the diagonal phase covariances are corrected for photon shot noise. This assumes the optical blur varies slowly within a phase cycle and the local bead positions are spatially uncorrelated. The bead-trace estimate is retained as `bead_depth` in modulation.json. Sparse fields, small images and carriers too close to the texture band use bead photometry. Both depth estimates include the uniform fluorescent sphere correction. Angles refer to the wavevector measured from +x toward +y in image coordinates. Maps extrapolate in regions with few beads. Downloads include the reusable point-emitter PSF archive, frame-aligned bead fit, modulation coefficients and sampled fields, and the field overview PNG.

For generated movies, the preview renders the aberrated point PSF used for the simulation. The estimator displays the simulated and fitted PSFs together, with true and estimated Noll coefficients, focus, XYZ drift, pattern pitch, orientation, field-center modulation depth and intensity ratio. Truth is retained in the browser for the selected generated movie and is used only for display. A TorchPSF point cloud below the PSFs shows each fitted bead once at its estimated XY position in the camera plane. Uploading a TIFF runs the ordinary fit.

See [the matched depth benchmark](depth-benchmark.md) for true-pupil and true-drift controls on identical pixels.
